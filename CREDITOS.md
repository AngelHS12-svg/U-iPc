# Créditos y recursos de U-iPC

- Proyecto: **U-iPC**.
- Autora: Lizbeth Valerio Garcia.
- Institución: Universidad Tecnológica de Oriental.
- Asignatura: Optativa de Videojuegos.
- Docente: Oliver Peregrina Luna.
- Cuatrimestre: décimo. Integrantes: una persona.
- Código C#, geometría procedural, disposición del taller, materiales, interfaz y tonos de audio: creados para este proyecto con asistencia de IA mediante Codex.
- Motor: Unity 6, sujeto a la licencia de Unity aplicable al usuario.
- Tipografía de interfaz: fuente disponible en el sistema operativo, cargada en tiempo de ejecución. No se distribuyen archivos de fuente del sistema en los fuentes del proyecto.
- Los textos 3D usan la fuente integrada de Unity.
- No se incorporaron modelos, texturas ni pistas de audio descargados de terceros.
- No se usaron Blender ni servicios generadores 3D de pago para esta versión.
- Los nombres de hardware NOVA son nombres ficticios de ambientación; no representan compatibilidad de productos reales.

La elegibilidad para Unity Personal y las condiciones del canal de publicación deben revisarse antes de publicar. Referencia oficial: https://unity.com/products/unity-personal
